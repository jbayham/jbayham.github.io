Forecasting Arches National Park Visitation with Weather

Published

November 4, 2025

Overview

This report extends the baseline visitation forecasting by incorporating weather variables. We pair readable intuition with collapsed code chunks so you can skim the narrative and expand the code as needed.

What you’ll see:

  • Data loading with weather checks
  • Feature engineering (lags, moving averages, anomalies, interactions)
  • Exploratory relationships: temperature/precipitation vs visitation, correlations
  • Train/test split (24-month holdout)
  • Methods:
    • Linear Regression (baseline vs. with weather vs. interactions)
    • ARIMA with external regressors (xreg)
    • Random Forest with weather features
  • Side-by-side model comparison, visualizations, and weather impact analysis

Data expected at data/arches_with_weather.csv. If missing, run fetch_weather_data.R first.

2) Feature Engineering

We create time indices, calendar features, lags, rolling means, weather anomalies, interactions, and seasonal indicators to help models learn richer patterns.

Build time, lag, rolling, anomaly, and interaction features 
cat("\n=== FEATURE ENGINEERING ===\n")

=== FEATURE ENGINEERING ===
Build time, lag, rolling, anomaly, and interaction features 
full_data <- full_data %>%
  arrange(Date) %>%
  mutate(
    # Time index
    TimeIndex = row_number(),

    # Calendar features
    MonthFactor = factor(Month),
    Quarter = quarter(Date),
    MonthName = month(Date, label = TRUE),

    # Lag features (previous year same month)
    Visits_Lag12 = lag(RecreationVisits, 12),

    # Weather lags
    Temp_Lag1 = lag(TempMean, 1),
    Precip_Lag1 = lag(TotalPrecipitation, 1),

    # Rolling visit stats
    Visits_MA3 = rollmean(RecreationVisits, k = 3, fill = NA, align = "right"),
    Visits_MA12 = rollmean(RecreationVisits, k = 12, fill = NA, align = "right"),

    # Weather anomalies (relative to overall mean)
    TempAnomaly = TempMean - mean(TempMean, na.rm = TRUE),
    PrecipAnomaly = TotalPrecipitation - mean(TotalPrecipitation, na.rm = TRUE),

    # Interaction term
    TempSunshine = TempMean * AvgSunshine,

    # Seasonal weather indicators
    IsSummer = ifelse(Month %in% 6:8, 1, 0),
    IsWinter = ifelse(Month %in% c(12, 1, 2), 1, 0),
    IsPleasantWeather = ifelse(TempMean > 50 & TempMean < 85 & TotalPrecipitation < 1, 1, 0)
  )

# Accuracy helper
calc_metrics <- function(actual, predicted, model_name) {
  mae <- mean(abs(actual - predicted), na.rm = TRUE)
  rmse <- sqrt(mean((actual - predicted)^2, na.rm = TRUE))
  mape <- mean(abs((actual - predicted) / actual), na.rm = TRUE) * 100
  cat("\n", model_name, ":\n", sep = "")
  cat("  MAE: ", format(mae, big.mark = ",", digits = 2), "\n", sep = "")
  cat("  RMSE:", format(rmse, big.mark = ",", digits = 2), "\n", sep = "")
  cat("  MAPE:", round(mape, 2), "%\n", sep = "")
  return(c(MAE = mae, RMSE = rmse, MAPE = mape))
}
