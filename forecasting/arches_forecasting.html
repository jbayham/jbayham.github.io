Overview

This report demonstrates several approaches to forecasting monthly visitation to Arches National Park. We mirror the methods used in the original R script and provide plain-English explanations before each code block:

  • Linear Regression with seasonal (monthly) effects
  • Time series models: ARIMA and ETS (Exponential Smoothing)
  • Machine Learning: Random Forest with feature engineering
  • Model comparison, visualizations, residual diagnostics, and future 24‑month forecasts

Data file expected: data/arches.csv (monthly recreation visits with columns Year, Month, RecreationVisits).

Method 3: Machine Learning (Random Forest)

We engineer calendar and lag features (e.g., prior‐year same month, short/long moving averages) and train a Random Forest regressor.

Engineer features, fit RF, evaluate 
cat("\n=== METHOD 3: RANDOM FOREST (MACHINE LEARNING) ===\n")

=== METHOD 3: RANDOM FOREST (MACHINE LEARNING) ===
Engineer features, fit RF, evaluate 
create_features <- function(data) {
  data %>%
    mutate(
      TimeIndex = row_number(),
      MonthFactor = factor(Month),
      Quarter = quarter(Date),
      Lag12 = lag(RecreationVisits, 12),
      MA3 = rollmean(RecreationVisits, k = 3, fill = NA, align = "right"),
      MA12 = rollmean(RecreationVisits, k = 12, fill = NA, align = "right"),
      Trend = row_number()
    )
}

# Build features across train+test to form correct lags
full_data_for_features <- bind_rows(
  train_data %>% mutate(Set = "train"),
  test_data %>% mutate(Set = "test")
) %>%
  create_features()

train_rf <- full_data_for_features %>%
  filter(Set == "train") %>%
  filter(!is.na(Lag12) & !is.na(MA3) & !is.na(MA12))

test_rf <- full_data_for_features %>%
  filter(Set == "test") %>%
  filter(!is.na(Lag12) & !is.na(MA3) & !is.na(MA12))

set.seed(42)
rf_model <- randomForest(
  RecreationVisits ~ TimeIndex + MonthFactor + Quarter + Lag12 + MA3 + MA12 + Trend,
  data = train_rf,
  ntree = 500,
  mtry = 3,
  importance = TRUE
)
